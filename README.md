# AlphaK · atualizações

Pacotes assinados dos aplicativos AlphaK. Os apps instalados nos clientes leem esta pasta e se atualizam sozinhos.

- `Instaladores AlphaK/<app>/latest.json`: versão publicada, tamanho, SHA-512 e assinatura Ed25519.
- `Instaladores AlphaK/<app>/<app>-<versao>.akpkg`: pacote da versão.

Os apps só instalam pacotes assinados pela chave de publicação da AlphaK. Este repositório não tem código-fonte, senhas nem configurações de clientes.
